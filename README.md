# Amnezia Config Server 🛡️

Легковесный веб-сервер на FastAPI, упакованный в Docker. Предназначен для раздачи установочных скриптов и генерации конфигураций для AmneziaVPN по HTTP-запросам.

## 🚀 Возможности
- **GET `/script`** — отдает bash-скрипт для первоначальной настройки.
- **GET `/generate`** — инициирует процесс создания нового конфига (эмулирует запрос к Amnezia) и сохраняет его.
- **GET `/configs/{id}`** — позволяет скачать уже сгенерированный конфиг по его ID.
- **Docker** — сервер полностью изолирован и легко разворачивается на любом хосте.
