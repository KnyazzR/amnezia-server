# AmneziaWG Config Proxy Server

Легковесный и безопасный FastAPI-сервер, который выступает прокси-прослойкой для генерации и выдачи конфигов AmneziaWG. 

Сервер взаимодействует с [amneziawg-api](https://github.com/taphix/amneziawg-api) по HTTP, скрывая от конечных пользователей прямые доступы к API-токенам и SSH-ключам инфраструктуры.

## 🚀 Возможности
- 🔒 **Защита API**: Все чувствительные эндпоинты защищены проверкой заголовка `X-API-Key`.
- 🐳 **Dockerized**: Полная готовность к развертыванию через Docker Compose.
- 🔄 **Автоматизация**: Генерация клиента, скачивание `.conf` файла и сохранение его локально в одном запросе.
- 📜 **Скрипт-эндпоинт**: Отдача bash-скрипта для автоматической настройки на стороне клиента.

## 📋 Требования
- Ubuntu (или любой другой Linux)
- Docker и Docker Compose
- Развернутый и работающий экземпляр [amneziawg-api](https://github.com/taphix/amneziawg-api)
